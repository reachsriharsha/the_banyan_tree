## 4. Endpoints & flow

| Endpoint | Auth | Body → Returns |
|---|---|---|
| `POST /api/v1/auth/otp/request` | none | `{email}` → `202` always (no user enumeration) |
| `POST /api/v1/auth/otp/verify` | none | `{email, code}` → `{access, refresh}` + sets session |
| `POST /api/v1/auth/refresh` | refresh token | rotates → new `{access, refresh}` |
| `POST /api/v1/auth/logout` | access | revokes session/family |
| `POST /api/v1/auth/dev-login` | **dev‑only flag** | `{email}` → tokens, skips OTP (the AC "fast path", for e2e) |

```
request:  email → rate-limit(Redis) → find user (silent if none)
                → gen 6-digit → store hash+expiry(otp_codes) → OtpSender.send_otp  → 202
verify:   email,code → load otp_codes → check expiry/lock/attempts
                → constant-time hash compare → OK → create session
                → mint access JWT (15m) + opaque refresh (30d, hashed, family) → 200
refresh:  token → hash lookup → if used_at set → REPLAY → revoke whole family → 401
                → else mark used, mint new pair in same family → 200
```

## 5. Token strategy

- **Access** = stateless JWT (HS256, `AKSHARA_JWT_SECRET`). Claims: `sub`(user_id), `tenant_id`, `role_keys`, `exp`(15m), `jti`. The `tenant_id` claim is exactly what the **M1‑06 tenant middleware** already expects, and `role_keys` feeds **M1‑09 RBAC** — so this slots into both.
- **Refresh** = opaque random string, only its `token_hash` stored; rotation on every use; reuse → revoke the whole `family_id`. Lives in `sessions`/`refresh_tokens` (already modelled).

## 6. Security baseline

OTP + refresh stored only as hashes; constant‑time compare (reuse the `secrets.compare_digest` pattern already in `deps.py`); `202`‑always on request to resist enumeration; lockout + dual rate limits; `jti` for traceability; emit `auth.otp.requested/verified/failed/locked` and `auth.session.created/refreshed/revoked/replay_detected` per the reserved taxonomy. JWT‑secret rotation and refresh storage join the **§14 Security** ledger.

| Concern | Dev | Production |

| **OTP delivery** | `ConsoleOtpSender` logs the code (you read it in the terminal); optional Mailpit for a real inbox UI | Real provider via HTTPS API (Resend/Postmark/SES) |
