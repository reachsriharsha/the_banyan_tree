There are **no default credentials** — auth is email-OTP, not password-based. You log in with whatever email you want, and the OTP code is delivered based on `EMAIL_PROVIDER` in `infra/.env`:

**Local dev (default: `EMAIL_PROVIDER=console`)**
1. Bring the stack up: `make up`
2. Open http://localhost:5173/ and enter any email at `/login`
3. Pull the OTP code from backend logs:
   ```
   docker compose logs backend | grep -o '"code":"[0-9]\{6\}"' | tail -n 1
   ```
4. Paste the 6-digit code into the verify field

The user is auto-created on first OTP verify. To make that user an admin on first creation, set `ADMIN_EMAILS=you@example.com` in `infra/.env` *before* their first login (it's a one-time bootstrap; later promotion needs a DB write).

**Test fixture shortcut** — if you don't want to grep logs every time:
```
ENV=test
TEST_OTP_EMAIL=you@example.com
TEST_OTP_CODE=123456
```
in `infra/.env` makes the verify code for that one email always equal `123456`. The backend refuses to start with these set unless `ENV=test`.

For staging/prod, switch `EMAIL_PROVIDER=resend` and set `RESEND_API_KEY` — see `docs/deployment/email-otp-setup.md`.
