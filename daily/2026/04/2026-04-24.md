## Brain Clone - macOS port + install fix

Main thread: Ported the WSL/Linux `install.sh` + `sync-claude-sessions.sh` in `/Users/swbs/src/brain_clone` to work on macOS, then fixed a bash 3.2 error.

2 commits landed on `main`:
- `ebfdd34` - updated support for macOS
- `b330378` - install error fix

Changes made:

1. Portable BSD vs GNU helpers: replaced `md5sum` -> `md5 -q`, `stat -c '%Y'` -> `stat -f '%m'`, `date -d @N` -> `date -r N`, and `sed -i "..."` -> `sed -i '' "..."` in both embedded and standalone sync scripts via runtime-detected `_hash_file` / `_mtime_epoch` / `_epoch_fmt` / `_sed_inplace` functions.
2. Node.js install on macOS: now errors out cleanly if Homebrew is missing instead of falling through to Debian `apt-get` path.
3. MCP HTTP daemon: added a `launchd` branch that writes `~/Library/LaunchAgents/com.qmd.mcp.plist` and uses `launchctl load`; kept the `systemd` branch for Linux/WSL. Re-install detection + teardown warning list now include the plist.
4. PATH hint: suggests `~/.zshrc` on macOS, `~/.bashrc` elsewhere.
5. Existing folders left alone: vault setup now skips collection dirs that already exist (including `/Users/swbs/src/the_banyan_tree`).
6. bash 3.2 fix: replaced `declare -A COL_NAMES / COL_CONTEXTS` with `col_name()` / `col_context()` case-statement functions, since macOS ships bash 3.2.57 without associative arrays support (error hit: `declare: -A: invalid option`).
